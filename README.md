# switch_ime

**IMEをトグルせず、好きなキーで日本語入力と英数字入力を直接切り替えます。**

`switch_ime` は、日本語入力のONとOFFにそれぞれ別のキーを割り当てられる、Windows向けの軽量な常駐ユーティリティです。

従来のトグル操作と異なり、**現在の入力モードを確認し、切り替えが必要な場合だけ**IMEに指示を送ります。日本語入力がすでにONの場合は再度切り替え指示を送らないため、変換未確定の文字列への不要な干渉を避けられます。

タスクトレイに常駐し、IME独自のキーカスタマイズ機能ではなくWindows APIを利用します。

同じWindowsセッション内では、EXEの配置場所や通常／管理者権限の違いにかかわらず、1つだけ常駐します。すでに起動している場合、後から起動したプロセスはキーボードフックを設置せずに終了します。

## 特長

### 日本語入力と英数字入力を別々のキーに割り当て

次の2つの操作に、それぞれ好きなキーを割り当てられます。

- **IME ON** — 日本語（ひらがな）入力へ切り替える。
- **IME OFF** — 英数字の直接入力へ切り替える。

例えば、「ひらがな」キーをIME ON、「変換」キーをIME OFFに設定できます。割り当てるキーは自由に変更できます。

### 必要なときだけ切り替える

`switch_ime` は、無条件に入力モードを切り替えません。

| 押したキー | 現在 `A` | 現在 `あ` |
| --- | --- | --- |
| IME ONキー | `あ` へ切り替え | 何もしない |
| IME OFFキー | 何もしない | `A` へ切り替え |

指定したモードになっている場合は、IMEへの切り替え指示を一切送りません。

特に、日本語の変換未確定状態でIME ONキーを再度押しても、不要なモード切り替え指示によって編集中の文字列に影響することを避けられます。

入力モードが取得できない場合も、切り替え指示は送りません。

### キーを自由に設定

シンプルな設定ダイアログで、割り当てたいキーを実際に押して登録します。

設定内容はEXEと同じフォルダの `switch_ime.ini` に保存され、変更後はアプリの再起動なしで反映されます。

設定画面を開いている間や設定を保存している間も、設定済みのキーでIMEを切り替えられます。キー登録欄にフォーカスがある間だけ、キーを登録用として扱います。

新しいキー設定は、保存に成功してから反映し、設定画面を閉じます。キャンセルした場合は従来の設定を維持します。

### Windowsへのサインイン時に自動起動

設定画面の「Windowsにサインインしたときに起動する」は、現在実行中のEXEの自動起動を設定します。

設定画面を開くと、サインイン中のユーザーのレジストリを読み、登録先のパスと現在のEXEのパスを照合します。一致すればチェックON、未登録または別の場所のEXEが登録されていればチェックOFFで表示します。チェックOFFでも、別の場所のEXEが自動起動に登録されている場合があります。

| 操作 | 動作 |
| --- | --- |
| チェックONでOK | 現在のEXEのパスを登録します。別の場所のEXEが登録されている場合は、現在のパスへ上書きします。 |
| チェックOFFでOK | 登録先が現在のEXEと一致する場合だけ解除します。別の場所のEXEが登録されている場合や未登録の場合は、レジストリを変更しません。 |
| キャンセル | チェック状態にかかわらず、自動起動の登録を変更しません。 |

OKを押した時点でも登録先を読み直して判定します。例えば、古い配置先のEXEが登録されている状態で、新しい配置先のEXEの設定画面を開くとチェックOFFになります。そのままOKまたはキャンセルを押しても古い登録は残ります。新しい配置先へ切り替えるには、チェックONにしてOKを押してください。

管理者権限で実行している場合も、サインイン中のユーザーのスタートアップに登録します。ユーザーを特定できない場合や登録先にアクセスできない場合は案内を表示し、自動起動欄をチェックOFFにして操作できない状態にします。この場合、既存の自動起動登録は変更しません。通常のユーザー権限で起動し直し（起動時のUACの確認をキャンセルして）、設定し直してください。キー設定は引き続き変更できます。

OKを押した際、INIの保存や自動起動の変更に失敗した場合は、エラーを表示して設定画面を開いたままにします。適用中のキー設定は変更しません。INIの保存に失敗した場合は、自動起動の変更を元に戻します。元に戻せなかった場合もエラーを表示します。修正して再度OKを押すか、キャンセルで閉じます。

自動起動の登録先はWindowsのユーザー別 `Run` レジストリで、INIには保存しません。EXEを移動した場合は、移動先で設定を開いて、チェックした状態でOKを押し、登録先を更新してください。

### 管理者権限のアプリでもIMEを切り替え

管理者権限で起動したアプリ上でのIME切り替えに対応しています。設定画面の「管理者権限で起動する」をONにしてOKを押すと、必要に応じてUACの確認後に `switch_ime` を管理者権限で起動し直します。初期値はOFFです。

設定をONにしている間は、以後の起動時にも必要に応じてUACの確認が表示されます。自動起動時も同様です。UACをキャンセルした場合は案内を表示して通常権限で常駐を続けるため、設定画面からOFFに戻せます。キャンセルだけでは設定は変わらず、次回起動時もUACの確認が表示されます。管理者権限で常駐している場合、OFFへの変更は次回の通常起動から反映します。

### 設定と終了のためのトレイアイコン

常駐中は「あ」の固定アイコンを表示します。
アイコンの右クリックメニューから **「設定」** または **「終了」** を選択できます。

### 軽量・ポータブル

C++とWin32 APIで実装しています。追加のアプリケーションフレームワーク、キーボードフック用DLL、インストーラーは不要です。

Release版はVC++ランタイムを静的リンクしているため、VC++再頒布可能パッケージの追加インストールも不要です。

## 動作環境

- Windows 11
- 本アプリで使用するWindowsのIME制御・入力機構に対応した日本語IME

IMEやアプリケーションによって動作が異なる場合があります。すべてのIMEでの動作を保証するものではありません。

## インストールと使い方

1. リリースパッケージが公開されている場合はそこから `switch_ime.exe` を入手するか、ソースコードからビルドします。
2. `switch_ime.ini` を作成・更新できるフォルダにEXEを配置します。
3. `switch_ime.exe` を起動します。
4. 初回起動時に設定ダイアログが表示されるので、**IME ON** と **IME OFF** に割り当てるキーを指定して **「OK」** を押します。
5. アプリがタスクトレイに常駐します。設定を変更する場合はアイコンを右クリックして **「設定」** を選択します。

DLL登録やインストーラーは必要ありません。

## 動作の仕組み

```text
設定したキーを押す
        |
        v
現在のIME入力モードを取得
        |
        +-- すでに目的のモード --> 切り替え指示なし
        |
        +-- 状態取得不可 -------> 切り替え指示なし
        |
        +-- 異なるモード
                 |
                 v
        対応するIME ON/OFFキーを送信
```

設定したキーの入力は低レベルキーボードフックで検出します。設定対象のキーだけを処理し、それ以外のキーボード入力には干渉しません。

切り替え要求は受付時のウィンドウには結びつけず、実行時点でフォーカスがある入力先のIME状態に従って実行します。状態取得中に入力先が変わった場合も要求を保持し、新しい入力先の状態を確認し直します。

設定画面を開いている間も、設定済みのキーでIMEを切り替えられます。キー登録欄にフォーカスがある間だけ、押したキーを登録用として扱い、IME切り替えは行いません。

## 技術資料：使用するWindows API

### 現在のIMEモードの取得

IME状態の取得には、WindowsのInput Method Manager（IMM）とIME制御メッセージを利用します。

- `ImmGetDefaultIMEWnd` — 入力先に対応するデフォルトのIMEウィンドウを取得する。
- `SendMessageTimeoutW` — IMEウィンドウへの問い合わせで無期限に待機しないようにする。
- `WM_IME_CONTROL` / `IMC_GETOPENSTATUS` — IMEのON/OFFを調べる。
- `WM_IME_CONTROL` / `IMC_GETCONVERSIONMODE` — 日本語入力か英数字入力かを区別するため、変換モードを取得する。

`IMC_GETOPENSTATUS` と `IMC_GETCONVERSIONMODE` は従来から使われている互換性重視の仕組みであり、WindowsやIMEの実装によって結果が異なる場合があります。

### 入力モードの切り替え

Win32 APIの `SendInput` で、次の仮想キーを送信します。

| 操作 | 仮想キー | 値 |
| --- | --- | --- |
| 日本語入力ON | `VK_IME_ON` | `0x16` |
| 英数字入力 / IME OFF | `VK_IME_OFF` | `0x1A` |

切り替え時にはKEYDOWNとKEYUPを送ります。

アプリが送信先のウィンドウを選んでIME変更メッセージを直接送るのではなく、Windowsの通常のキーボード入力経路を使用します。

なお、`SendInput` に成功してもIMEのモード変更まで保証されるわけではありません。管理者権限のアプリで利用する場合は「管理者権限で起動する」をONにしてください。UACの確認画面など、セキュアデスクトップは対象外です。

### キーボードフックとトレイアイコン

- `SetWindowsHookExW(WH_KEYBOARD_LL)` — 他プロセスへのフックDLL注入なしで、設定されたキーを検出する。
- `Shell_NotifyIconW` — 固定アイコンの登録・削除と、Explorer再起動時の再登録を行う。
